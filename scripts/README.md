# Scripts Directory

Folder ini berisi script utility untuk development dan maintenance.

## Contents

| Script | Description |
|--------|-------------|
| `debug_import.py` | Debug import issues |
| `debug_settings.py` | Debug settings configuration |
| `fix_apps.py` | Fix app configurations |
| `rebuild_rbac.py` | Rebuild RBAC roles & permissions |
| `run_tests.py` | Run test suite |
| `test_rbac.py` | Test RBAC system |
| `verify_api.py` | Verify API endpoints |
| `verify_communication.py` | Verify communication features |
| `verify_content.py` | Verify content features |
| `verify_finance.py` | Verify finance features |

## Usage

Run from project root:

```bash
python scripts/rebuild_rbac.py
python scripts/verify_api.py
```
